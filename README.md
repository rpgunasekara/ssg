# Custom Static Site Generator
Websites are fun to build and design, but for the purposes of conveying information on a regular basis, it's annoying to build individual HTML pages. Lots of great SSGs already exist, but not understanding anything under the hood frustrated me. I found [David K. Zhang's](https://www.dkzhang.com/websites.html) site and his note on building statis sites. It inspired me to try and take a shot at building my own SSG.

## Status
Currently learning how to transform a Markdown file into an HTML one.

## Tools
Building this in WSL using Python. I would like to try to learn a new language like Go and rewrite this in the future, but for my current purposes Python works just fine.
